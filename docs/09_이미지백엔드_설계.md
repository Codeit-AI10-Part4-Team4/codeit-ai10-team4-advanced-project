# 이미지 백엔드 설계

**v0.7 · 2026-08-24 · 사람 없는 재촬영과 공통 정보 포스터 반영**

> 이 문서가 현재 이미지 구현의 기준입니다. 과거의 “실사진을 한 픽셀도 바꾸지 않는 보정”은
> `local` 프로필과 OpenAI 실패 시의 안전 폴백으로 유지합니다.

## 1. 현재 결정

사용자가 상품 사진을 올리면 결과물 목적에 맞춰 광고 사진을 다시 연출합니다.

| 조건 | 감성 피드형 | 정보 포스터형 |
|---|---|---|
| `IMAGE_PROFILE=openai` | 감성형 전용 AI 재촬영 1회 | 포스터 카드 전용 AI 재촬영 1회 |
| `IMAGE_PROFILE=local` | 원본 좌표를 유지한 안전 색보정 | 안전 색보정 사진 전체를 카드로 사용 |
| OpenAI 실패 | 안전 색보정으로 자동 전환 | 안전 색보정으로 자동 전환 |
| 사진 없음 | 기존 장면 생성 | 기존 주인공 생성 + 포스터 조판 |

AI 재촬영은 원본 복원이 아니라 **원본을 참고한 새로운 상업 촬영**입니다. 배경·카메라·조명·소품·
구도는 적극적으로 바꿀 수 있습니다. 결과에는 `연출된 이미지` 표시를 붙입니다.

한글 문구·가격·상호·주소는 이미지 모델에게 그리게 하지 않습니다. 모델은 글자 없는 광고 사진만
만들고, 실제 문구는 Pillow 조판이 정확히 얹습니다.

사진 유무와 업종에 관계없이 정보 포스터는 따뜻한 종이 배경·중앙 3:2 사진 카드·상품명·큰 가격·
하단 상호라는 한 가지 레이아웃을 사용합니다. 가격은 주문서 값을 직접 조판하고 문구에 같은 금액이
있으면 중복 표시하지 않습니다.

## 2. 전체 흐름

```text
사장님 사진
  ├─ 감성형
  │   ├─ openai → 1:1 감성 광고 재촬영(high) → 상단 한글 조판
  │   └─ local/실패 → 안전 보정 → 상단 한글 조판
  │
  └─ 포스터형
      ├─ openai → 3:2 포스터 카드 재촬영(high) → 정보 포스터 조판
      └─ local/실패 → 안전 보정 → 정보 포스터 조판

사진 없음
  ├─ 감성형 → build_scene_prompt → generate_scene → 한글 조판
  └─ 포스터형 → build_hero_prompt → generate_background → 포스터 조판
```

레퍼런스·스케치를 함께 올린 감성형은 이번 변경에서 기존 계약을 유지합니다. 실제 상품 누끼와
명시한 분위기·구도를 조합합니다.

## 3. 감성형과 포스터형을 두 번 만드는 이유

두 결과물은 필요한 사진 구도가 다릅니다.

- 감성형: 1:1, 생활감 있는 공간, 상품은 하단 중심, 왼쪽 위 문구 여백
- 포스터형: 3:2, 중앙 상품 중심, 가장자리 여백, 정보 카드 안에서 잘리지 않는 구도

같은 사진을 억지로 재사용하면 둘 중 하나의 구도가 나빠집니다. 따라서 최초 생성과 “사진만 다시
만들기”는 이미지 API 2회입니다. 문구만 바꿀 때는 재료 사진을 재사용하므로 0회입니다.

| 사용자 행동 | 이미지 API 호출 |
|---|---:|
| 사진을 올리고 최초 이미지 생성 | 2회 |
| 문구만 변경 | 0회 |
| 사진만 다시 생성 | 2회 |
| `local` 프로필 | 0회 |

## 4. 재촬영 프롬프트 계약

공통 원칙:

1. 업로드 사진을 실제 광고 대상의 시각 참고로 사용합니다.
2. 배경·촬영 각도·조명·중립 소품·스타일링은 자유롭게 재구성합니다.
3. 음식이면 자연스럽고 먹음직스럽게, 비식품이면 업종에 맞는 상업 사진으로 만듭니다.
4. 플라스틱 질감·과한 HDR·가짜 보케·중복 사물·불가능한 형태를 피합니다.
5. 사장님이 말하지 않은 원산지·수상·인증·할인·품질 주장은 만들지 않습니다.
6. 모델이 읽을 수 있는 한글·가격·상호·캡션·워터마크를 그리지 않습니다.
7. 사람·얼굴·손·팔·손가락·신체 일부와 사람의 반사·실루엣을 만들지 않습니다. 사진 가장자리에도
   잘린 신체가 들어오지 않게 합니다.

감성형 추가 계약:

- 따뜻하고 자연스러운 동네 가게의 에디토리얼 광고 사진
- 왼쪽 위에 조판용 저복잡도 여백
- 실제 카메라로 촬영한 듯한 빛·재질·깊이

포스터형 추가 계약:

- 중앙에 완결된 상품 구도
- 카드 크롭을 위한 가장자리 여백
- 정돈된 세트와 균일한 상업 조명
- 포스터 바깥 정보 조판을 방해하지 않는 단순한 배경

## 5. 품질과 규격

| 용도 | OpenAI 요청 | 앱 재료 크기 | 최종 출력 |
|---|---|---|---|
| 감성형 | `1024x1024`, `quality=high` | 1080×1080 | 1080×1080 PNG |
| 포스터형 | `1536x1024`, `quality=high` | 1080×720 | 1080×1080 PNG |
| 사진 없는 기존 생성 | 기존 계약 유지 | 1080 기준 | 1080×1080 PNG |

비정사각형 결과는 비율을 보존한 채 카드에 맞춥니다. OpenAI의 3:2 결과와 사진 카드 비율을 맞춰
불필요한 흐린 여백을 줄이고, 강제 정사각 `resize`로 찌그러뜨리지 않습니다.

## 6. 실패와 사실 표시

OpenAI 재촬영이 실패하면 광고 전체를 중단하지 않습니다.

```text
AI 재촬영 실패
  → enhance_uploaded_photo
  → 안전 보정도 실패하면 EXIF 방향을 반영한 RGB 원본
```

- AI 성공: `staged=True`, `연출된 이미지` 표시
- 안전 보정 폴백: `staged=False`, 연출 표시 없음
- 두 스타일이 함께 실패해도 같은 화면 안내는 한 번만 쌓습니다.
- 외부 오류 원문과 키 정보는 로그에만 남기고 사용자 문장에 노출하지 않습니다.

## 8. 30장 실험과 결정 변경

2026-08-23에는 “원본 상품을 정확히 유지하면서 배경만 개선”하는 GPT 편집을 30장에 적용했습니다.
사용 가능 4장·조건부 9장·사용 불가 17장이었고, 상품 수량·라벨·상차림이 바뀌었습니다. 그래서
정확한 원본 보존을 약속하는 자동 편집은 폐기했습니다.

2026-08-24에는 제품 방향을 다시 정했습니다. 사용자가 AI 광고 제작임을 알고 결과의 시각 품질을
우선한다는 전제 아래, 어중간한 “원본 보정”이 아니라 **명시적인 AI 광고 재촬영**으로 전환했습니다.
이 변경은 다음 세 가지로 정직하게 구분합니다.

1. 결과에 `연출된 이미지`를 표시합니다.
2. OpenAI 실패와 비용 없는 환경에는 안전 보정 폴백을 유지합니다.
3. 정확한 상품 보존이 필요한 레퍼런스·스케치 조합은 기존 누끼 계약을 유지합니다.

즉 30장 실패를 무시한 것이 아니라, 실패한 “정확 보존 편집”과 새 “창의적 광고 재촬영”을 서로
다른 기능 계약으로 분리한 것입니다.

## 9. 검증 계약

1. `openai` + 업로드 사진 감성형은 `style=simple`을 정확히 1회 호출합니다.
2. `openai` + 업로드 사진 포스터형은 `style=poster`를 정확히 1회 호출합니다.
3. 두 프롬프트의 구도 지시는 서로 다릅니다.
4. 재촬영은 `quality=high`를 사용합니다.
5. 감성형은 정사각, 포스터 재료는 가로 비율을 사용합니다.
6. AI 성공은 `staged=True`, 폴백은 `staged=False`입니다.
7. 사진 없는 기존 감성형·포스터형은 재촬영 함수를 호출하지 않습니다.
8. 테스트에서 `_openai_restage` 대역을 빠뜨리면 즉시 실패하고 실제 과금 호출은 차단됩니다.
9. 문구 변경은 이미지 재촬영을 다시 호출하지 않습니다.
10. 사진 유무 경로 모두 사람·손·팔 금지 문구를 최종 이미지 프롬프트에 포함합니다.
11. 사진 유무 포스터 모두 같은 3:2 사진 카드와 `warm_bakery` 종이 틀을 사용합니다.
12. 주문서 가격은 큰 가격 칸에 한 번만 표시합니다.

## 10. 설정

```dotenv
# 비용 없이 로컬 생성 + 업로드 사진 안전 보정
IMAGE_PROFILE=local

# 사진 없는 GPT 생성 + 업로드 사진 고품질 AI 광고 재촬영
IMAGE_PROFILE=openai
OPENAI_API_KEY=...
```

기본 예제 환경은 과금 사고를 막기 위해 `local`을 유지합니다. 실제 배포에서 고품질 결과를
사용하려면 서버 secret에 키를 넣고 `IMAGE_PROFILE=openai`를 명시해야 합니다.

## 11. 남은 후속

- `_notices` 프로세스 전역 목록을 요청/사용자별 결과로 분리
- 공개 배포의 사용자별·일별 이미지 호출 상한과 접근 통제
- 다양한 비식품 업종 실사진으로 재촬영 품질 회귀 확인
- AI 재촬영 결과가 광고 대상과 지나치게 달라질 때 사용자가 원본 안전 보정을 선택하는 UI
- 4:5·네이버 플레이스 등 추가 규격은 1:1 배포가 안정된 뒤 확장
