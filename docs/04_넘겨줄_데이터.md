# 넘겨줄 데이터

> 사장님 말에서 뽑아낸 정보를 **이미지 생성 · 품질 검증** 에 넘기는 형식.
> 작성일: 2026-08-05

---

## 1. 형식

| 이름 | 자료형 | 필수 | 설명 |
|---|---|:---:|---|
| `industry` | `str` | ✅ | `industries.yaml` 의 id — 예: `"cafe"` |
| `goal` | `str` | ✅ | `"copy"` \| `"image"` |
| `format` | `str` | ✅ | `formats.yaml` 의 id — 예: `"insta_feed"` |
| `style` | `str` | ✅ | `styles.yaml` 의 id — 예: `"warm"` |
| `product` | `str` | ✅ | 홍보 대상 — 예: `"크로플"` |
| `photo` | `PIL.Image \| None` | — | 제품 사진. **있으면 `preserve`, 없으면 `scene`** |
| `items` | `list[dict]` | — | `[{"name": str, "price": str}]` · **AI 가 만들지 않음** |
| `request` | `str` | — | 자유 요청 |
| `with_text` | `bool` | — | 이미지에 글자를 얹을지 |
| `store_name` | `str \| None` | — | 상호 |
| `store_phone` | `str \| None` | — | 전단지·POP 에 필요 |
| `store_address` | `str \| None` | — | 전단지·현수막에 필요 |
| `mode` | `str` | ✅ | 아래 표로 자동 결정 |
| `legal_tags` | `list[str]` | ✅ | `industry` + `format` 의 법령 태그 합집합 |
| `raw_utterance` | `str` | ✅ | 사장님이 한 말 그대로 |

**규칙**
- 값은 **라벨이 아니라 id** (`"cafe"` ✅ / `"카페·디저트"` ❌)
- 못 알아들은 항목은 **`None`** — 억지로 채우지 않음
- 새 항목은 **항상 선택**으로 추가 (받는 쪽이 모르면 무시)

**`mode` 결정표**

| photo | mode | 하는 일 |
|:---:|---|---|
| ✓ | `preserve` | 누끼 → SDXL 배경 생성 → **원본 상품 합성** |
| ✗ | `scene` | SDXL text-to-image → **"연출된 이미지" 표기** |

> 레퍼런스(`reference`)·스케치(`sketch`)는 **나중에 추가**합니다.
> 그때 `mode` 값이 늘어나도 **기존 두 값은 그대로**이므로 받는 쪽 코드는 안 깨집니다.

## 2. 예시

> **NLU 완성을 기다리지 마세요.** 아래를 손으로 넣고 각자 개발하면 됩니다.

**A. 카페 · 사진 있음 · 인스타**

```python
{
    "industry": "cafe", "goal": "image", "format": "insta_feed",
    "style": "warm", "product": "크로플",
    "photo": <Image>,
    "items": [{"name": "크로플", "price": "4,500원"}],
    "request": "", "with_text": True,
    "store_name": "○○카페", "store_phone": None, "store_address": None,
    "mode": "preserve", "legal_tags": ["general", "food", "online"],
    "raw_utterance": "우리 카페 크로플 인스타에 올릴 사진 감성적으로",
}
```

**B. 학원 · 사진 없음 · 전단지**

```python
{
    "industry": "academy", "goal": "image", "format": "insta_feed",
    "style": "modern", "product": "여름 특강",
    "photo": None,
    "items": [{"name": "중등 수학", "price": "월 20만원"}],
    "request": "", "with_text": True,
    "store_name": "○○학원", "store_phone": "02-000-0000", "store_address": "서울시 ...",
    "mode": "scene", "legal_tags": ["general", "academy", "online"],
    "raw_utterance": "학원 여름 특강 모집 전단지 만들어줘",
}
```

**C. 문구만**

```python
{
    "industry": "restaurant", "goal": "copy", "format": "insta_feed",
    "style": "bold", "product": "삼겹살",
    "photo": <Image>,
    "items": [], "request": "", "with_text": True,
    "store_name": None, "store_phone": None, "store_address": None,
    "mode": "preserve", "legal_tags": ["general", "food", "online"],
    "raw_utterance": "삼겹살 특가 문구 좀 뽑아줘",
}
```
